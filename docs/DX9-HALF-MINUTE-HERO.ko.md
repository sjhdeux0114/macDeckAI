# 용사30 Direct3D 9 조사

Steam App ID 214830, `HMH.exe` x86. 현재 상태는 `failing`이며 실제 플레이 안정성·프레임률·화면 크기를 다시 검증한다. 수정은 정확한 App ID 214830에만 적용하고 DmC(App ID 220440)의 Clear/sRGB/query-yield 보완을 공유하지 않는다.

## 폐기한 D9VK 경로

2026-10-19 사용자 지시에 따라 D9VK → Metal 모드를 제품과 시험 진입점에서 완전히 제거했다. 이 경로는 타이틀 또는 플레이에서 검은 화면, 화면 잘림, 심한 버벅임, `vkQueueSubmit` 크래시를 보여 사용할 수 없는 것으로 판정했다.

- UI의 Direct3D 9 렌더러 선택과 콘솔 순환 동작을 제거했다.
- 라이브러리의 `d3d9Mode` 모델과 native DLL override, 자동 `dxvk.conf` 생성 코드를 제거했다. 기존 JSON의 `d3d9Mode: native` 키는 알 수 없는 레거시 키로 무시되고 내장 Direct3D 9 경로만 사용한다.
- 용사30 D9VK 전용 trial 생성, 실행 command, 빌드·패치·테스트 스크립트를 제거했다.
- 게임 폴더에 남은 시험 `d3d9.dll`은 과거 기록 SHA-256과 정확히 일치할 때만 별도 복원 백업 후 분리한다. 사용자 파일은 해시 근거 없이 삭제하지 않는다.

과거 D9VK 조사에서 YV12 포맷 조회와 x86 로깅 호출 규약 결함을 확인했지만, 수정 후보 역시 실제 게임 성능과 안정성을 만족하지 못했다. 해당 분석은 역사적 실패 근거이며 재활성화 가능한 제품 옵션이 아니다.

## 현재 조사 원칙

- 실제 로그인 Steam과 공유 prefix를 사용하되 App ID 214830 전용 프로필과 렌더러 규칙으로 범위를 제한한다.
- 게임 폴더 DLL·INI를 실행 준비나 라이브러리 갱신 중 자동 수정하지 않는다.
- 새로운 직접 Metal 후보는 계정 없는 GPU 검사와 다른 App ID 비적용 검사를 먼저 통과한 뒤 실제 게임에 배포한다.
- 검은 화면·잘림·프레임 지연은 각각 창 크기, 실제 GPU drawable, Present 간격과 API 집계를 분리해 판단한다.
- 실제 한 장면 성공을 장시간 정상 구동으로 승격하지 않는다.

## 재현 도구

`scripts/wine-hmh-window-probe.cpp`는 정확한 `HMH.exe` 창만 찾아 크기·DPI를 출력하고, 명시적으로 요청된 경우에만 Enter를 전달한다. Steam 인증 정보나 임의 입력, 프로세스 메모리는 수집하지 않는다.
