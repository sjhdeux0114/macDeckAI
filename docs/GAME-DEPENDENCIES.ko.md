# 게임 필수 런타임 자동 준비

MacDeck은 Steam을 열기 전에 설치된 게임의 .NET Framework와 Visual C++ 요구 사항을 확인한다. Steam이 열려 있거나 같은 Wine 환경에서 게임·다른 설치 프로그램이 실행 중이면 설치를 보류한다. Big Picture 안에서 새로 설치한 게임은 다음 Steam 시작 전에 검사한다.

## 지원 범위

| 종류 | 지원 패키지 |
|---|---|
| Visual C++ | 2005, 2008, 2010, 2012, 2013: 각각 x86/x64 |
| Visual C++ 14 | 2015–2022 호환 재배포 패키지: x86/x64 |
| .NET Framework | 3.5 SP1(2.0/3.x 포함), 4.0, 4.5, 4.6.2, 4.7.2, 4.8 |

4.5.1/4.5.2/4.6 계열 요구에는 4.6.2, 4.7 계열 요구에는 4.7.2를 선택한다. 4.x는 한 환경에서 상위 버전이 교체하므로 동시에 여러 4.x가 요구되면 **요청된 것 중 가장 높은 버전**을 준비한다. 임의로 모든 게임을 4.8로 올리지 않는다. .NET 4.8.1 및 최신 .NET Desktop/Core 런타임은 이 카탈로그의 지원 대상이 아니다.

## 사용 방법

1. Steam과 게임을 종료하고 MacDeck의 **Steam Big Picture 열기**를 선택한다.
2. 누락 패키지가 있으면 공식 다운로드·해시 확인·설치·설치 후 확인 순서로 준비한다. 진행 상태는 앱에 표시된다.
3. 실패한 패키지는 자동 반복하지 않는다. 네트워크나 실행 중인 작업을 확인한 후 **런타임 → 필수 런타임 다시 준비**에서 명시적으로 재시도한다.

일반 Steam 게임 실행 버튼도 같은 사전 검사에 연결된다. 게임마다 별도 Steam 로그인을 만들거나 인증 파일을 복사하지 않는다. 설치는 Wine 환경 내부에 이루어지며 macOS에 Windows 런타임을 설치하는 기능이 아니다. Wine 환경이 저장된 Mac 볼륨에 설치 공간이 필요하며 게임이 외장 디스크에 있어도 재배포 패키지는 Wine 환경에 설치된다.

## 요구 사항 판별 및 검증

- 정확한 Steam App ID의 DB `requiredRuntimes`, 게임 배포 `installscript.vdf`, 표준 redist 경로 및 PE import 표를 사용한다.
- 게임 VDF의 명령·실행 파일·종료 코드 무시 지시·성공 레지스트리 키는 실행하지 않는다. 허용 목록의 Microsoft 공식 URL 및 고정 SHA-256 패키지만 실행한다.
- PE 정적 분석은 실행 파일과 DLL의 일반/지연 import에서 VC 계열·아키텍처를 읽는다. CLR 실행 파일의 메타데이터는 기본 .NET 요구를 알려준다. Unity/Mono의 관리 DLL만 보고 Windows .NET을 설치하지 않는다.
- 스캔은 깊이·파일 수가 제한돼 있고 동적 로딩·특수 설치 스크립트·패키지의 세부 최소 빌드 요구를 모두 찾아내지는 못한다. 자동 탐지 실패는 의존성이 없다는 증거가 아니다. 알려진 추가 요구는 정확한 App ID의 `requiredRuntimes`에 카탈로그 ID로 등록할 수 있다.
- Wine의 가짜 DLL이나 설치 프로그램 종료 코드만으로 성공 처리하지 않는다. 네이티브 PE와 버전 레지스트리를 확인하고 .NET은 작은 프로그램의 컴파일·실행·예외 처리도 검사한다. WoW64 환경에서는 x86/x64 양쪽을 검사한다.
- .NET 설치를 위해 일시 변경한 Wine Windows 버전은 백업 후 복구한다. 복구가 남아 있으면 Steam 시작을 보류한다.
- CLR은 요구가 확인된 고유 실행 파일에만 활성화하고 다른 게임은 기존 CLR 차단을 유지한다. 같은 이름의 실행 파일이 여러 게임에 있으면 활성화를 보류한다.

재배포 패키지는 같은 Wine 환경의 공통 구성요소이다. 설치 후 기존 정상 게임에 영향이 전혀 없다고 보장하지 않으며, 기존 정상 기준을 자동 갱신하지 않는다. 구성 변경이 보호 기준과 충돌하면 재검증이 필요하다. 설치 성공과 실제 게임·Metal 성공은 별개다.

## 기록

`~/Library/Application Support/MacDeck/Dependencies/`에 prefix별 패키지 ID, 관련 Steam App ID, 해시, 시각, 종료 코드, 설치 후 검증 상태를 기록한다. 실패는 24시간 자동 재시도를 유예하며 수동 재시도가 우선한다. 오류 신고 ZIP에는 해당 게임 App ID가 포함된 제한된 설치 기록만 첨부한다. 원시 Steam 인증 출력·계정 파일·메모리 덤프는 포함하지 않는다.

카탈로그 URL 및 해시 근거: [Winetricks 공식 소스](https://github.com/Winetricks/winetricks/blob/master/src/winetricks), 2026-10-19 확인. 공식 배포 파일이 바뀌어 SHA-256이 달라지면 설치를 중단한다. 임의로 새 해시를 신뢰하지 않는다.

자동 준비가 실제 설치를 시작하면 해당 Wine 환경의 VC/.NET 핵심 DLL 해시도 정상 실행 기준에 포함한다. 기존 정상 기준과 달라지면 자동 승인하지 않고 재검증을 요구할 수 있다. 설치 기록의 이전 상태는 `Dependencies/<prefix key>/History/`에 보존한다. 의존성이 이미 설치돼 있으면 재설치 대신 검사를 수행한다.
