# 게임별 호환성 DB와 오류 신고

2026-10-18 구현. 용사30·엘든링의 실행 실패는 미해결이다. UI나 자체 검사가 통과해도 실제 플레이 성공을 뜻하지 않는다.

## 게임 식별과 기록

앱 데이터 폴더의 `Compatibility/game-profiles.json`이 로컬 DB다. 앱의 **호환성 DB** 탭에서 상태를 보고 게임 관리 화면으로 들어간다. Steam 게임 키는 `steam:<App ID>`이며 이름을 바꿔도 동일한 게임이다. 비 Steam 게임은 라이브러리 UUID를 사용한다. 이름이 유사하다는 이유로 설정을 자동 적용하지 않는다.

초기 기록은 RE3(952060), DMC5(601150)의 과거 사용자 구동 보고와 용사30(214830), 엘든링(1245620)의 최신 실패 보고를 구분한다. 과거 성공 보고는 현재 빌드 검증이나 정상 실행 보호 활성화를 뜻하지 않는다. 나머지 게임은 미검증으로 등록된다.

게임 관리에서 **정상 실행 기준 저장**은 사용자가 실제 플레이를 확인한 뒤 누른다. 런처 환경·실행 인수 해시·Wine/주요 DXMT/D3D12/DXGI/MoltenVK 브리지 및 게임 폴더 렌더러 해시를 기록한다. 다음 실행에서 달라지면 실행을 보류한다. 기준을 가진 게임이 있으면 공유 런타임 업데이트도 보류한다. 보호 해제는 해당 게임 기록만 변경한다. 실패 기록은 다른 게임의 상태나 실행 설정을 바꾸지 않는다.

이는 게임 설치 파일 전체, 모든 런타임 종속성, Steam 클라이언트나 macOS 버전을 고정하거나 이전 런타임을 자동 복원하는 기능은 아니다. 공유 런타임 바이너리를 수정하는 실험에는 별도 런타임/환경 복제가 필요하다. Steam의 실행 요청에 설정된 환경이 이미 실행 중인 Steam의 게임 자식에 전달됐다고 보장하지 않는다.

## 수정 범위 제한

- 게임마다 프로필 revision, 검증 상태, 메모와 선택적인 실험 환경을 둔다. 실험은 기본 끔이다.
- 허용된 렌더링·동기화 환경 변수만 직접 실행 프로세스에 적용한다. 셸 명령, 임의 환경 변수, DLL 배포와 전역 레지스트리 수정은 프로필로 실행할 수 없다.
- Steam 공유 클라이언트에 실험 환경을 주입하지 않는다. `steam.exe`를 통한 실행에 실험 환경이 설정되면 명시적으로 보류한다.
- 실행 준비가 다른 게임의 INI, 게임 폴더 DLL, 보호 런처를 자동 수정하지 않도록 해당 경로를 제거했다. 이전에 이미 변경된 게임 파일·레지스트리를 자동 원복하지는 않았다.
- 명시적 전역 그래픽 모드 전환은 여전히 공유 Wine/DXGI를 사용한다. 동시에 서로 다른 렌더러 런타임을 격리하는 기능은 아니다.
- 잘못된 DB나 허용되지 않은 설정은 원본을 보존하고 오류로 처리한다.

## 오류 신고

**게임 카드 → X/□ 또는 키보드 X → 오류 신고 메일**에서 재현 순서와 증상을 적고 **ZIP 만들고 메일 작성**을 선택한다. 받는 사람은 `sjhdeux@gmail.com`이다. macOS 메일 작성 서비스가 ZIP을 첨부하며, 사용자가 내용을 검토하고 직접 전송한다. 메일 서비스를 사용할 수 없거나 오류가 나면 저장된 ZIP을 Finder에 표시한다. 메일 계정이 실제로 설정된 환경의 전송까지 자동 테스트하지 않았다.

ZIP은 `Logs/SupportReports/<보고서 UUID>/`에 보관한다. 최신 해당 게임 세션과 연결된 Steam 렌더러 로그만 대상으로 삼는다. 인증 설정·원시 Steam stdout/stderr·메모리 덤프·심볼릭 링크를 수집하지 않는다. 게임 로그에는 개인정보나 로컬 경로가 포함될 수 있으므로 전송 전 검토해야 한다. 로그는 파일당 마지막 512KiB, 전체 약 12MiB, 렌더러 파일 200개로 제한하며 제한 내용을 JSON에 남긴다.

## DB 등록용 JSON

ZIP의 `MacDeck-Report/issue-report.json`은 schema 1이다. 핵심 필드:

| 필드 | 의미 |
| --- | --- |
| `reportID` | 중복 제보 식별 UUID |
| `gameKey`, `steamAppID`, `gameName` | DB 키, Steam App ID(비 Steam은 생략 가능), 표시 이름 |
| `engine`, `profileRevision`, `recordedStatus` | 제보 시점의 프로필 정보 |
| `reportStatus` | `unverified-user-report`; 제보는 미검증 |
| `automaticPromotionAllowed` | `false`; 성공 상태로 자동 승격하지 않음 |
| `sessionID`, `sessionKind` | 원본 실행 세션과 Steam 실행 요청/직접 실행 구분 |
| `reportedAt`, `reproduction` | ISO 8601 시각과 사용자 재현 설명 |
| `includedFiles`, `limitations` | 포함 파일, 잘림/제외 및 해석 한계 |

이는 DB 수집에 사용할 JSON 계약이며 메일 서버·자동 수신·서버 DB 삽입 기능을 구축한 것은 아니다. 제보의 App ID와 게임 키를 확인해 검토 대기 기록으로 수집하고, 실제 재현 검증 후 해당 게임의 프로필 revision을 갱신해야 한다. 다른 게임의 성공 기준이나 전역 설정을 덮어쓰면 안 된다.

## 조작

연결된 PlayStation 패드는 ✕/○/□와 L1/R1, Xbox·일반 패드는 A/B/X와 LB/RB로 안내한다. 키보드 안내는 항상 함께 표시한다. 패드 미연결 시 Xbox 표기를 사용한다. 방향키/스틱으로 3열 카드 이동, 확인으로 실행/선택, 뒤로로 복귀, X/□로 게임 관리, 어깨 버튼으로 화면 전환한다. 키보드는 방향키·Enter/Space·Esc·X·Tab/Shift-Tab이다. Menu/OPTIONS는 Steam 화면으로 이동하며 Steam을 자동 실행하지 않는다. 이름·경로·재현 내용 입력과 시스템 파일 선택은 기본 macOS 편집/파일 선택 UI를 사용한다.
